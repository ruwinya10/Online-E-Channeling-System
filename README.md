## 🌐 Overview
**HeloMed** is a comprehensive e-channeling web system developed as part of a Software Engineering group assignment using **UML modeling**. It enables patients to book doctor and lab appointments online, manage profiles, and handle secure payments, while administrators oversee doctor availability. The system supports guests for browsing and registered users for full functionality, integrating with a database and bank system for seamless healthcare management. All design artifacts, including use case diagrams, scenarios, sequence diagrams, and communication diagrams, are included to illustrate the system's architecture.

## 📐 Design Artifacts
The project includes:
- **Use Case Diagram**: Overall system interactions for actors (Guest, Patient, Doctor, Admin, Database, Bank).
- **Use Case Scenarios**: Detailed flows for login, profile edits, appointments, and admin tasks.
- **Sequence & Communication Diagrams**: For key processes like login/OTP, profile updates, booking, payments, and doctor addition.
These UML diagrams model the OOP design, ensuring modular and extensible architecture.
---
## 🛠️ Technology Stack
- **UML Modeling** (Use Cases, Sequences, Communications)
