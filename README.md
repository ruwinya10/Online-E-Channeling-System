## 🌐 Overview

**HaloMed** is a web application developed using object-oriented design principles that enables patients to book doctor and lab appointments online, manage profiles, and process secure payments. The system supports both guest browsing and registered user workflows, integrates with a database and bank API (simulated for academic use), and includes notification services for confirmations.
